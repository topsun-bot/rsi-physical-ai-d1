# D1 视频 + 截图晾衣绳 (`D1Clothesline.app` & `D1LiveMonitor.app`)

把 **1 楼俯视摄像头的实时视频流** 和 **macOS 系统快捷键截图 (`⌘⇧3 / ⌘⇧4 / ⌘⇧5`)** 一起挂在屏幕顶部菜单栏下方的"晾衣绳"上：平时藏在菜单栏里不挡视野，鼠标往菜单栏一停（约 `0.25s`）就自动滑下；只有鼠标点在卡片上才响应，卡片之间的空白区域点击直接穿透到底层窗口。

> 灵感来自开源项目 [alejandrobujan/tendedero](https://github.com/alejandrobujan/tendedero)，在此基础上扩展为 **实时 RTSP 视频流 + 机械臂遥测 + 系统截图/录屏一体化晾衣架**。

---

## 核心功能

1. **4 路实时视频常驻晾衣绳（左侧）**
   - **1F 俯视全景** + **左臂 103** + **中臂 102** + **右臂 101** 局部特写同源零拷贝裁切（单路 `ffmpeg` MJPEG 管道驱动 4 张卡片，流畅 18–20 FPS）。
   - 每张机械臂卡片底部实时显示 `2.5 Hz` 只读 UDP 遥测（`J0` 角度与 `爪` 夹爪开合度，**只读不发任何控制指令**）。
2. **接管系统截图/录屏快捷键（右侧，替代原版 Tendedero）**
   - 直接按系统自带的 **`⌘⇧3`（全屏截图）**、**`⌘⇧4`（区域截图）**、**`⌘⇧5`（截图/录屏工具栏）**，新截的图或录屏会自动夹在晾衣绳右侧。
   - 程序退出时自动将 macOS 系统截图保存位置恢复为 `~/Desktop`，不会导致退出后系统截图失效。
3. **菜单栏自动收放 + 点击穿透**
   - 鼠标停在菜单栏 `0.25s` 自动滑下，移开 `0.55s` 自动收起；也可开启「一直晾着（不自动收起）」或用全局快捷键 `⌃⌥D` 随时切换。
   - 采用自定义 `LinePanel` 子区域命中检测：仅卡片区域拦截鼠标，绳子周围空白处 100% 穿透。
4. **独立多画面监控浮窗 (`D1LiveMonitor.app`)**
   - 除顶部晾衣绳外，还提供可自由拖动、缩放、置顶、调节透明度（`35%–100%`）的 4 宫格/单路切换独立浮窗监控器。

## 一、启动方式

任选一种：

1. **双击启动**
   - 顶部晾衣绳：双击 `D1Clothesline.app`
   - 独立监控浮窗：双击 `D1LiveMonitor.app`
2. **终端一键启动**
   ```bash
   # 启动顶部视频+截图晾衣绳
   ./scripts/run_mac_clothesline.sh

   # 启动独立 4 宫格实时监控浮窗
   ./scripts/run_mac_floating_monitor.sh
   ```

> 启动后晾衣绳会先自动放下来展示画面；鼠标移上去再移开一次后，即进入自动收放模式。右上角菜单栏常驻图标为 **🧺**（固定展开模式下显示 **🧺📌**）。

## 二、日常操作说明

### 1. 呼出与收起晾衣绳

| 操作 | 效果 |
| :--- | :--- |
| 鼠标**停在屏幕最顶部菜单栏**约 `0.25s` | 晾衣绳带着实时视频和截图滑下来 |
| 鼠标**离开卡片区域**约 `0.55s` / 点击菜单栏 | 晾衣绳自动收回菜单栏上方 |
| 按快捷键 `⌃ Control` + `⌥ Option` + `D` | 随时手动 放下 / 收起 |

### 2. 视频卡片操作（左侧 4 张）

| 操作 | 效果 |
| :--- | :--- |
| **单击**视频卡片 | 弹出该路画面的独立放大浮窗（可拖动、可拉大），再点一次关闭 |
| **双击**视频卡片 | 启动完整版 `D1LiveMonitor.app` 实时监控浮窗 |
| **按住拖拽**视频卡片到微信 / 钉钉 / Finder | 将当前实时视频帧直接导出为 PNG 图片拖入目标应用 |
| **右键**视频卡片 | 放大查看、拷贝当前帧、保存截图、从绳上取下、清空截图、**退出程序** |

### 3. 截图/录屏卡片操作（右侧，按 `⌘⇧3 / ⌘⇧4 / ⌘⇧5` 自动生成）

| 操作 | 效果 |
| :--- | :--- |
| 直接按 **`⌘⇧3` / `⌘⇧4` / `⌘⇧5`** | 截图完成后自动挂到晾衣绳最右侧，并自动滑下展示 |
| **单击**截图卡片 | 直接复制图片到剪贴板（卡片闪白提示，可直接 `⌘V` 粘贴） |
| **双击**截图卡片 | 用系统「预览 (Preview)」打开原图/录屏 |
| **按住拖拽**截图卡片 | 直接把截图文件拖进微信、钉钉、浏览器、Finder 等任意窗口 |
| **右键**截图卡片 | 拷贝图片、另存到桌面、从绳上取下、移到废纸篓、清空全部截图 |

## 三、菜单栏设置（点击右上角 🧺）

- **放下 / 收起晾衣绳 (`⌃⌥D`)**
- **一直晾着（不自动收起）**：需要全程盯画面时开启
- **鼠标停在菜单栏时滑下**：关闭后仅通过快捷键 `⌃⌥D` 或截图触发滑下
- **晾上的视频**：单独勾选需要挂在绳上的机位，或一键「全部重新挂上」
- **清空晾上的截图**：一键收走绳上所有历史截图
- **尺寸**：小 / 中 / 大 / 特大
- **视频源**：流畅（`640×360` 子码流，默认低延迟）/ 超清（`stream1` 主码流）

---

## 四、退出方式

任选一种：

1. 放下晾衣绳 → **右键任意一张卡片 → 「退出 D1 视频晾衣绳」**
2. 点击菜单栏 **🧺 → 「退出 D1 视频晾衣绳」**
3. 终端执行：
   ```bash
   ./scripts/run_mac_clothesline.sh --stop
   ```

> 退出时程序会自动将 macOS 系统截图目录恢复回桌面 (`~/Desktop`)。

```text
├── macos_clothesline/
│   ├── D1Clothesline.swift          # 顶部视频+截图晾衣绳主程序源码 (AppKit 原生)
│   ├── build_app.sh                 # 编译并打包 D1Clothesline.app
│   └── README.md                    # 使用说明
├── macos_monitor/
│   ├── D1LiveMonitor.swift          # 独立多宫格实时监控浮窗源码
│   └── build_app.sh                 # 编译并打包 D1LiveMonitor.app
└── scripts/
    ├── run_mac_clothesline.sh       # 晾衣绳启动/停止/重编脚本 (--rebuild | --stop | --snapshot)
    └── run_mac_floating_monitor.sh  # 独立浮窗启动/停止脚本
```

### 自定义视频流地址

程序按以下优先级读取 RTSP 流地址：
1. 环境变量 `D1_RTSP_SUB_STREAM`（子码流）与 `D1_RTSP_STREAM`（主码流）
2. 本地配置文件 `~/.config/d1_clothesline/D1_RTSP_SUB_STREAM` 与 `~/.config/d1_clothesline/D1_RTSP_STREAM`

编译命令：
```bash
./macos_clothesline/build_app.sh
./macos_monitor/build_app.sh
```
